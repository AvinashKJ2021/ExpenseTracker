# Expense Tracker

A simple **console-based Expense Tracker** built in **C#** using **.NET 7**.  
This project allows users to **add, view, and calculate total expenses** using a **case-insensitive dictionary** and follows **object-oriented programming (OOP) principles**.

---

## Features

- Add new expenses with **description** and **amount**.
- **View all expenses** in a neat format.
- Calculate **total expenses**.
- Handles **duplicate descriptions** by summing amounts.
- Validates **user input** for non-empty descriptions and positive amounts.
- **Case-insensitive** descriptions (`Food` and `food` are treated the same).
- Built with **OOP principles**:
  - `Expense` class represents an expense.
  - `ExpenseManager` class handles all logic.
  - `Program` class handles user input and menu.
